NMR Analyzer 1.6.0 adds automatic updates and builds for every desktop
platform, including Intel Macs. Processing and analysis are unchanged from 1.5.1.

### New
- **Automatic updates.** Once a day an installed copy asks GitHub for the latest
  release, downloads the file for your system, verifies it against
  `SHA256SUMS.txt` and installs it when you close the program (or immediately with
  *Restart now*). Help → Automatic updates offers *download and install*, *only
  tell me* and *off*; Help → Check for updates… checks on demand. Source and pip
  installs are never modified.
- **More downloads**: separate macOS disk images for Apple silicon and **Intel**,
  a Windows portable zip, a Debian/Ubuntu `.deb`, a Linux `.tar.gz` with a per-user
  `install.sh`, and `SHA256SUMS.txt`.
- `--selftest` and `--update` command-line options.

### Changed
- Builds are now one folder (with an `.app` on macOS) on every platform instead
  of a single self-unpacking file: faster start-up, and updates replace the folder
  as a whole.
- The Windows installer installs for the current user by default (no
  administrator rights); *Install for all users* is still offered.
- File names now carry the processor: `…-windows-x64-setup.exe`,
  `…-macos-arm64.dmg`, `…-macos-x86_64.dmg`, `…-linux-x86_64.tar.gz`.

Note for 1.5.1 users: 1.5.1 has no updater, so install 1.6.0 once by hand;
later versions arrive automatically.
